# Python Expense Tracker

A beginner-friendly command-line Expense Tracker built using Python.

## Features

- Add expenses
- View all expenses
- Calculate total spending
- Exit the application
- Validate date format

## Concepts Used

- Variables
- Lists
- Dictionaries
- Loops
- Conditional statements
- User input
- Exception handling
- datetime module

## How to Run

Make sure Python is installed on your system.

Run:

```bash
python expense-tracker.py
